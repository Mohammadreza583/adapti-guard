# ADAPTI-GUARD Experiment Tracking

## Directory Structure

- `registry.csv` — machine-readable experiment registry
- `experiment_history.md` — chronological research history
- `runs/EXP-XXX_VX/` — complete run artifacts
- `protocols/` — fixed evaluation protocols
- `archive/` — superseded/invalidated artifacts
- `logs/` — execution logs

## Reproducibility

Every verified experiment should record:

1. Experiment ID
2. Version
3. Timestamp
4. Git commit
5. Dataset path
6. Dataset SHA-256
7. Split
8. Sample count
9. Random seed
10. Evaluation metrics
11. Exact execution command
12. Environment
13. Notes and decision

## Dataset Policy

Raw datasets are immutable.

Processed datasets must be generated by scripts and documented by checksum.

## Result Policy

A result must not be considered final unless:

- the evaluation protocol is fixed,
- the dataset split is fixed,
- the code version is identifiable,
- the run is reproducible,
- and the result is stored under `experiments/runs/`.
